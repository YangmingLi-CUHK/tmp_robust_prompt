# Source provenance

- Paper-designated repository: https://github.com/zjunet/GPF
- Branch: `main`
- Retrieved: 2026-08-02
- Scope: all source files, scripts, README, and license from the repository root, `bio/`, and `chem/`.
- Omitted: `bio/pretrained_models/` and `chem/pretrained_models/` binary checkpoints. These large weights are not source code and remain available from the upstream repository.

GPF and GPF-Plus are two methods from the same NeurIPS 2023 paper and the same repository. This directory is a source-only snapshot because a normal clone attempted to transfer the bundled model weights and did not complete reliably.
