2.2 GraphConvolution.forward

def forward(self, input, adj):
    support = torch.mm(input, self.weight)   # [N, in] @ [in, out] → [N, out]
    output  = torch.spmm(adj, support)        # [N, N] @ [N, out] → [N, out]
    return output + self.bias                 # [N, out]

4. DynamicPrompt Generator

The paper's default prompt generator for Cora. norm_if=True, IB=True.

4.1 Architecture

class DynamicPrompt(nn.Module):
    def __init__(self, nfeat=1433, nhid=1433, ...):
        self.prompt_g  = GraphConvolution(1433, 1433)    # weight [1433, 1433]
        self.gamma_1   = nn.Linear(1433, 1433, bias=False) # weight [1433, 1433]
        # norm_if=True: no beta_1, no L2 normalization
        self.lrelu     = nn.LeakyReLU(0.2)
    # Total params: 1433² + 1433² = 4,106,978

5. x_prompt Generator (Simpler Variant)

class x_prompt(nn.Module):
    def __init__(self, nfeat=1433, ...):
        self.gc1 = nn.Sequential(nn.Linear(1433, 1433))
        # Total params: 1433² = 2,053,489

    def forward(self, x, adj, adj_a, att=False):
        return F.relu(self.gc1(x))     # [N, 1433] @ [1433, 1433]^T → ReLU → [N, 1433]
        # NOTE: adj and adj_a are IGNORED. No graph structure is used.
StepOperationShape
1Linear(1433, 1433)(x)[2708, 1433] @ [1433, 1433]^T = [2708, 1433]
2ReLU(·)[2708, 1433]

This is a feature-only residual transform: x → (x + ReLU(Linear(x))) / 2. No graph structure (KNN or topology) is used in prompt generation. The adversarial PGD still perturbs the adjacency during training, but the prompt generator cannot see it.

6. CLUB / Information Bottleneck

CLUB (Contrastive Log-ratio Upper Bound) estimates mutual information I(P; H) between prompt P and noisy representation H. Used when IB=True.

6.1 Architecture

class CLUB(nn.Module):
    def __init__(self, dim_P=1433, dim_H=7, hclub=64, hlayer=1):
        # Both mu_net and logvar_net: Linear(1433→64) → ReLU → Linear(64→7)
        self.mu_net     = Sequential(Linear(1433,64), ReLU(), Linear(64,7))
        self.logvar_net = Sequential(Linear(1433,64), ReLU(), Linear(64,7))
    # Total params: 2 × (1433×64 + 64 + 64×7 + 7) = 184,462

6.2 Forward — MI Upper Bound

StepOperationShapeNote
1mu = mu_net(P)[N, 7]P = x_prompt [N, 1433]
2logvar = logvar_net(P)[N, 7]
3positive = −½ Σ((H−μ)² / exp(logvar))[N]Log-likelihood of H under Gaussian(μ, exp(logvar))
4H_shuffle = H[randperm(N)][N, 7]Break dependency P↔H by shuffling
5negative = −½ Σ((H_shuf−μ)² / exp(logvar))[N]
6I_ub = mean(positive - negative)scalarMI upper bound: I(P;H) ≤ E[log p(h|p)] − E[log p(h'|p)]

6.3 Learning Loss (for CLUB optimizer)

club_loss = 0.5 * Σ( (μ − H)² / exp(logvar) + logvar ).mean()
# Minimizes negative log-likelihood of H given P, improving the MI estimator

6.4 Training Dynamics

CLUB has its own optimizer (Adam, lr=1e-3). Each training iteration:

# 1. Compute IB loss (MI upper bound)
loss_ib = club_module(x_prompt, H_noisy)       # scalar

# 2. Joint loss, update prompt generator
loss_train = loss_kl + 0.05 * loss_ib
optimizer.zero_grad(); loss_train.backward(); optimizer.step()

# 3. Update CLUB estimator (5 inner iterations)
for _ in range(5):
    club_loss = club_module.learning_loss(x_prompt.detach(), H_noisy.detach())
    optimizer_club.zero_grad(); club_loss.backward(); optimizer_club.step()

The IB loss encourages the prompt to carry minimal information about the noisy representation — i.e., the prompt should focus on the clean signal, not the perturbation.

7. Reference: SimPGCN (WSDM '21)

Node Similarity Preserving Graph Convolutional Networks — the paper AttrPrompt's Prompt Learning Module is based on.

7.1 Core Idea

GCN destroys original feature similarity through Laplacian smoothing. SimPGCN preserves it by (a) adaptively mixing the structure graph with a KNN feature graph, and (b) explicitly regressing pairwise feature similarity in a self-supervised loss.

7.2 Per-Layer Computation

StepEquationShape
1s(l) = sigmoid(H(l−1) · Ws + bs)[N, d] @ [d, 1] = [N, 1]
2P(l) = s(l) ∗ Ãnorm + (1−s(l)) ∗ Af,norm[N, N]
3K(l) = H(l−1) · WK + bK[N, d] @ [d, 1] = [N, 1]
4P̃(l) = P(l) + γ · diag(K1, …, KN)[N, N]
5H(l) = σ(P̃(l) · H(l−1) · W(l))[N, N] @ [N, d] @ [d, d'] = [N, d']

7.3 Self-Supervised Loss

S_ij = cosine(x_i, x_j)                                          # [1] scalar
L_self = Σ_{(i,j)∈T} ‖ f_w( H_i^(1) − H_j^(1) ) − S_ij ‖²      # MSE regression

# f_w: Linear(d→1), H^(1): hidden reps from 1st SimPGCN layer
# T: 5 most similar + 5 most dissimilar node pairs per node
L_total = L_class + λ · L_self

7.4 Comparison: SimPGCN vs AttrPrompt DynamicPrompt

AspectSimPGCNAttrPrompt DynamicPrompt
How graphs interact Linear interpolation of two normalized adjacency matrices:
P = s·Ã + (1−s)·A_f, then convolution		 Element-wise gating: KNN graph generates a prompt, structure graph modulates it via gate:
prompt = γ ⊙ GCN(X, A_f) where γ = f(A·X)
Per-node adaptivity s_i ∈ (0,1) — one scalar per node that controls structure vs. feature graph mixing ratio γ_i ∈ (0.8, ∞)^{1433} — one scalar per feature dimension per node, controlling which dimensions of the KNN prompt to amplify/attenuate

Key Structural Difference
SimPGCN mixes two graphs (adjacency matrices) and does one convolution. AttrPrompt uses one graph to generate a feature-space perturbation (prompt) and the other graph to gate it. These are fundamentally different operations — the former is in the spectral/graph domain, the latter is in the feature domain.

8. Reference: TopologyAttack (IJCAI '19)

Topology Attack and Defense for Graph Neural Networks: An Optimization Perspective — the paper AttrPrompt's Adversarial Training is based on.

8.1 PGD Topology Attack (Algorithm 2)

StepOperationShape/DomainNote
1Perturbation variable s ∈ {0,1}nn = N(N−1)/2Binary: each edge either exists or not
2Convex relaxation: s ∈ [0,1]n[n]Relax binary → continuous for gradient descent
3Constraint: S = {s | 1Ts ≤ ε, s ∈ [0,1]n}simplexε = max #edges to perturb (e.g. 5% of existing edges)
4PGD: s(t) = ProjS[s(t-1) − η ∇f(s)][n]Project onto simplex (bisection over dual variable)
5After PGD: random sample K binary vectors from sPick the one with best attack loss, respecting 1Ts ≤ ε
6Attack loss: f = −CE or f = max(Z_y − max_{c≠y} Z_c, −κ)scalarCE-type or CW-type loss on target nodes

8.2 Robust Training (Algorithm 4)

# Alternating min-max optimization
for t = 1..T:
    # Inner: PGD to find worst-case topology s given model W^(t-1)
    s^(t) = PGD( s^(t-1), W^(t-1) )      # maximize CE loss on training nodes

    # Outer: Update model weights to be robust against s^(t)
    W^(t) = W^(t-1) + β · ∇_W CE( s^(t), W^(t-1) )   # gradient ASCENT on CE

# The model W is TRAINED to be robust against worst-case edge perturbations.

Key Structural Difference
TopologyAttack's robust training updates model weights to resist edge perturbations — it's model-level adversarial training. AttrPrompt freezes the model and trains a prompt to compensate for perturbations — it's input-level adversarial training. The perturbation space also differs: TopologyAttack uses binary edge addition/deletion with a cardinality budget; AttrPrompt uses continuous perturbation of normalized adjacency values with a box constraint.
