3. 结论

NSP tip 在中等污染有效、且更稳定：
  • ptb=0.15：Acc 0.0600 → 0.0824（+37.4%），是三档中唯一明确的正向收益。
  • ptb=0.05 / 0.25：与基线基本持平（Δ≈0），未见负交互。
  • 稳定性：基线在 0.05 有 1/5 seed NaN，NSP 全 5 seed 正常；NSP 在 0.05 的 std 也更小（0.022 vs 0.042）。
但需清醒看待：
  • 三档 Acc 全 ≤ 18%，远低于 clean linear-probe ~60% — 仍处 Meeting 15 所述「高 ptb 崩盘区 / GCL 悖论」，NSP 只是崩盘区内略好，未改变大局。
  • nsp_threshold=0.3、order=2 均为未调的默认值；+37% 很可能不是最优操作点。
  • 缺 clean(0.0) 基线 → NSP tip 对干净精度的代价未知，这是判断其价值的关键缺口。

4. 数据可用性说明

0.0 / 0.1 / 0.2 全部缺失（含 clean）：数据加载器按 Meta_Self_Cora_{ptb}.pt 拼路径，浓度字符串保留了尾零 → 找 ..._0.00.pt / _0.10.pt / _0.20.pt，而实际文件是 _0.0 / _0.1 / _0.2，全部 FileNotFoundError。 凡是含尾零的浓度（0.00 / 0.10 / 0.20）都失败，因此 clean 也没跑出来。0.05 / 0.15 / 0.25 恰好无尾零冲突，正常完成。
修复方式（零代码）：把命令里的 --attack_method Meta_Self-0.00 / -0.10 / -0.20 改成 -0.0 / -0.1 / -0.2 重跑即可补齐 clean 与 0.1 / 0.2。
