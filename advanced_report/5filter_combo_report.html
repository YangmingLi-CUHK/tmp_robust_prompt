Analysis & Key Findings

1. Fix verified — focusedcleaner_pt now properly disabled. With the task.py fix (threshold < 0 → key removed from pt_dict), the 5-filter permutation experiment now correctly isolates individual filter contributions. The focusedcleaner_pt no longer trains its 50-epoch LP model when "off" (threshold = -1.0). This report replaces the previous buggy version where fc was always active.
2. Single-filter clean ranking (NSP true-label): ood=0.5901 > nsp=0.5822 > degree=0.5775 > fc=0.5702 > sim=0.5208
3. Single-filter clean ranking (NSP-IA pseudo-label): ood=0.5323 > degree=0.5307 > fc=0.5061 > sim=0.4821 > nsp=0.4383
4. NSP true-label: accuracy collapses under attack. Best clean = 0.5983 → Best M-0.25 = 0.1155 (drop = 0.483). On clean data, the prompt achieves ~0.59 with 35 labels. Under M-0.25, the best any combo achieves is 0.1155 — barely above random (1/7 ≈ 0.143). This confirms the fundamental difficulty: RobustPrompt-T cannot maintain robustness under heavy graph perturbation in a true few-shot setting. The previous report's higher M-0.25 numbers were artifacts of the focusedcleaner-always-active bug.
5. NSP-IA: near-flat accuracy across ptb — confirms test leakage. Best clean = 0.5820 → Best M-0.25 = 0.5606 (drop = 0.021). The IA pseudo-label expansion (35 → ~595 labels, sampled from test set) creates a model that appears "robust" because it has already seen the test distribution during training. This is not genuine robustness — see meeting15_root_cause.html for the full analysis. Notably, NSP-IA single-filter clean (0.5323) is lower than NSP true-label (0.5901), suggesting pseudo-label noise hurts more than the extra labels help on clean data.
6. Multi-filter combos: marginal clean gain, harmful under attack. At clean: best single = 0.5901 vs best multi = 0.5983 (Δ = +0.0083). At M-0.25: best single = 0.1155 vs best multi = 0.1116 (Δ = -0.0039). Adding more filters does not improve robustness — the best M-0.25 performer is a single filter (fc = 0.1155), and multi-filter combos are slightly worse under attack.
7. sim_pt is unstable and degrades most combos. sim alone has NaN instability (1 ptb levels with 0/5 valid seeds, clean only 4/5). Adding sim to any combo reduces clean accuracy — except when ood is also present (sim+ood ≈ ood alone). Worst interaction: sim+nsp = 0.4930 (lowest 2-filter combo). Recommendation: exclude sim_pt from future experiments.
8. nsp_pt and focusedcleaner_pt perform on par with original filters. The two new filters are competitive: nsp (0.5822 clean) slightly edges degree (0.5775), fc (0.5702) is close behind. At M-0.25, fc is actually the best single filter (0.1155). Both new filters are valid additions to the defense tip family.
