排除歧义：哪些表象不能作为“污染预训练”的证据

命名 Attack_data 路径

它是统一数据包装器。真正选择由 attackmethod 与 ptb_rate 共同决定；预训练活动代码传的是 0.0。

增强 GraphCL 的边/节点变化

GraphCL 基于 clean LCC 生成自监督 view。它会改动训练视图，但无攻击损失、无 victim/surrogate、无非零 ptb，不能等价为 poisoning。

脚本 adaptive poisoning

task_muti_adaptive.sh 的 poisoning 和 ptb 参数位于 --attack_downstream 后；只影响 NodeTask 加载的下游图。

路径名 pre_trained_model_adaptive

这是 checkpoint 路径名，不是 provenance 证据。当前活动预训练代码没有非零 adaptive graph 输入；相关 “adaptive clean” loader 还是注释状态且 ptb 为 0。

GraphCL 增强的精确限定

GraphCL.py:29-52, 104-109 默认 aug1='dropN'、aug2='permE'；perturbation.py:5-21, 23-69 实现节点删除、边删除和特征 mask。permE 名称虽像 edge permutation，当前实现实际上只随机保留一部分边。两次 graph_views 还复用同一 g 对象，没有 clone，因此 view 可能串行受前一次原地修改影响；这是实现细节/潜在增强偏差，但仍不是攻击图预训练。

所有预训练入口的交叉验证

GraphCL、GraphMAE 通过 NodePretrain 进入 0.0 LCC；Edgepred_Gprompt 通过 load4link_prediction_single_graph → load4node_demo2；NodeMultiGprompt 通过 process.load_data → load4node_demo2；图分类预训练则由 load4graph 读取 TUDataset，没有 attack loader。预训练入口及 prompt_graph/pretrain/** 中没有 attack、ptb、poison 参数命中。

证据边界：当前快照能证明与不能证明什么

判断状态理由
论文设定是否 clean pretrain可证明第 5 页明文。
当前源码若按活动路径运行会加载哪张预训练基图可证明load4node_demo2 硬编码 Meta_Self-0.0 LCC。
非零攻击图是否进入当前预训练入口可排除预训练入口无 attack/ptb 参数；静态调用图没有从 attack loader 到 pretrain class 的活动边。
脚本引用的历史 checkpoint 是否确由当前 clean 路径生成不可证明文件夹中没有任何 .pth/.pt、raw adjacency、训练日志或 git commit metadata。
Meta_Self-0.0.pt 的内容是否逐边等于 clean LCC不可内容验证实际数据文件不在快照；只能由活动参数、生成器逻辑、作者注释和论文定义形成一致证据链。
