IA-PT Pseudo-Label Analysis — Data Leakage & Results

Generated: 2026-07-11  |  Source: logs/pseudo_label_attempt1/  |  256-dim peak BB + 64-dim BB
TL;DR — IA-PT 的 595 标签扩展确实存在测试集泄漏（get_psu_labels() 从 idx_test 选取伪标签）。 MLP 教师精度仅 36-39%（远低于 linear probe 64%），伪标签 61-64% 是错误的。 但得益于 595 标签的"量胜于质"，256-dim M-0.25 达到 0.47-0.58（远超 35 标签的 ~0.10），甚至出现"不降反升"（attacked 0.54 > clean 0.46）。 64-dim clean 0.50 vs M-0.25 0.48，几乎持平。

4. Summary

1. 泄漏确认 — 伪标签来自 idx_test（2408 个测试节点中选 560 个）。这不是标准的 semi-supervised learning。

2. MLP 弱，但量胜于质 — MLP 精度仅 36-39%（61-64% 伪标签错误），但 595 标签的规模效应仍远超 35 标签。IA-PT 在 M-0.25 上达到 0.48-0.55，而 35 标签版本仅为 0.08-0.12。

3. "不降反升"是伪标签泄漏的直接后果 — MLP 不看图结构，攻击不影响伪标签质量。因此攻击图上的 595 伪标签与干净图上的 595 伪标签质量几乎相同。prompt 在更多标签上训练 → 性能反超干净图的 35 标签版本。

4. Clean 仍低于 linear probe — 即使有 595 标签，IA-PT clean (0.46-0.50) 仍远低于 linear probe (0.64)。prompt 的核心缺陷（输入空间污染、p_plus token bank 过拟合）没有被 IA-PT 解决。

5. 论文 Table 1 的 IA-PT 数字可以部分复现 — 论文 Cora+GraphCL IA-PT: Clean 57.82, M-0.25 58.82。我们 256-dim: Clean ~0.46, M-0.25 0.55。M-0.25 的 0.55 接近论文 58.82（差 4pp 在 seed 波动范围内）。但 clean 差了 11pp（0.46 vs 57.82）——这无法用伪标签解释，因为 clean 图上的 MLP 也是同等的弱。
