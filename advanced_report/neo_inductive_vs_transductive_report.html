2. NA 根因分析

2a. 为什么 Inductive 远不如 Transductive 稳定？

Transductive 在全图（Cora 2708 节点，~5000+ 边）上训练，而 Inductive 在 k-hop 子图（5–300 节点，~10–500 边）上训练。差异的数学根源：

  1. τ-tune 空边风险：子图边数少。当 pt_threshold=0.25 的 cosine 阈值剪枝后，子图可变为无边形（edge_index 形状 (2,0)）。Ours 有空边守卫（MSE→0）但 KL loss 依赖的子图结构也随之消失。
  2. 小批量效应：batch_size=100 个子图，但每个子图的 prompt 是独立计算的。当 sim_pt 或 degree_pt 在某子图选中 0 个节点时，KL loss 的 len(...)==0 → continue 使该子图的 prompt 失去正则化 → 数值发散。
  3. p_plus Token Bank（231K 参数）在子图级别过拟合：每个子图仅 5-shot 中心节点标签，231K 参数的 token bank 学习的是子图结构而非语义特征。

2b. 为什么 Original 在 ptb≥0.05 时有效 seed 比 Ours 多？

这是数据中最反直觉的发现。两个版本的核心差异在 边剪枝的时机：

Original (forward-pruning)Ours (τ-tune two-pass)
剪枝依据prompt 作用后的 特征 cosine一轮 GNN 后的 embedding cosine
GNN 调用单次两次（中间 embedding→剪枝→第二次）
攻击边检测Prompt 直接在特征空间偏移 → 攻击边端点特征差异被保留 → 易检测GNN message-passing 平滑了攻击边端点的 embedding → 攻击边更难被 cosine 阈值检测
剪枝效果（受攻击图）更激进——攻击边更可能被剪掉更保守——GNN 混合了干净/攻击节点信息

假说：Original 在受攻击图上的 forward-pruning 实际上起到了 更强的攻击边过滤 作用，降低了训练噪声，因此更多 seed 存活。Ours 的 τ-tune（embedding 级剪枝）反而保留了更多攻击边，训练噪声更大 → 更多 seed 发散至 NaN。

这解释了为什么 Original 在干净图（ptb=0.0）有效 seed 更少（3 vs 7）——在没有攻击边时，forward-pruning 的激进性变成了劣势（过度剪枝 → 信息损失 → NaN），而 Ours 的保守策略更安全。

2c. 哪个 Filter 更容易 NaN？

结论：不是特定 filter，是系统性不稳定。

从上表 1b/1c 可见：

  • 各 combo 的 NaN 分布较为均匀，没有哪个 tip（sim/degree/ood）显著更差。
  • 三 tip 组合（sim+degree+ood）的 NaN 率并未显著高于单 tip——KL loss 对每个 tip 独立判断 len==0 → continue，不会因 tip 数量增加而累积风险。
  • degree_pt 理论上有更高风险（子图中度 ≤ 1 的叶节点占比大 → 选中节点少 → KL 正则缺失），但数据上并未显著体现。

本质问题是 随机种子 决定了 prompt 初始方向——某些种子恰好收敛，某些发散。这是极小训练集（35 标签 × 子图级别）上高维非凸优化的固有不稳定性。

5. 结论

5a. NA 根因

  1. Inductive 训练本质不稳定：k-hop 子图（5–300 节点）远小于全图（2708 节点），τ-tune 在小子图上容易剪空所有边。两个版本均有 78%–71% 的 NaN 率。
  2. 不是特定 filter 的问题：各 tip combo 的 NaN 分布均匀。没有哪个 tip（sim/degree/ood）显著更差。
  3. Transductive 非常稳定：4.7% NaN 率——全图边数多，τ-tune 不会空边。

5b. Original vs Ours — 受攻击时的反转

  1. Clean (ptb=0.0)：Ours 有效 seed 更多（7 vs 3），精度相近。Ours 的保守 τ-tune 在干净图上更安全。
  2. Attacked (ptb≥0.05)：Original 有效 seed 反超 Ours。Original 的 forward-pruning（特征级余弦剪枝）比 Ours 的 τ-tune（embedding 级余弦剪枝）更能识别攻击边——因为 GNN 的 message-passing 会"修复"攻击边端点的 embedding 差异。
  3. 精度水平：两个 Inductive 版本在相同 ptb 的有效精度相近（~0.60@clean, ~0.10–0.34@attacked），说明判别能力相似。差异在于 存活率（谁不 NaN）。

5c. Inductive vs Transductive 鲁棒性

在有有效数据的点上：

  • Clean (ptb=0.0)：Inductive 有效精度 ~0.58–0.65，Transductive ~0.49–0.59。Inductive 略高，但样本量极少（1-2 seed vs 4-5 seed），结论置信度低。
  • Attacked：Transductive 全面优于 Inductive——不是精度更高（相近），而是 不 NaN。在高 ptb 下，所有方法的精度都接近随机（1/7≈0.143），符合 CLAUDE.md 记录的 GCL 悖论。

5d. 建议

  1. 关闭 p_plus：--no_p_plus 将 231K→4 参数，应大幅改善 inductive 稳定性。
  2. 增大 smallest_size：从 100→200，降低子图被剪空的概率。
  3. 混合策略：在干净图上用 Ours（τ-tune），在受攻击图上用 Original（forward-pruning）。或者设计一个自适应切换机制。
  4. Original 对照实验：在原版基础上仅加梯度裁剪后重新跑——这将隔离"梯度裁剪 vs forward-pruning"的效应。
