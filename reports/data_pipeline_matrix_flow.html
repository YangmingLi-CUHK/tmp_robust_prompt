# 每个 batch: ~10 子图拼接 batch1.x [N_batch, 1433] # N_batch = Σ n_i ≈ 130~140 batch1.edge_index [2, E_batch] # E_batch = Σ e_i batch1.batch [N_batch] # 节点→子图归属索引

3.2 核心步骤 A：add_muti_pt — 三 Filter 分选 + Prompt 注入

代码: prompt_graph/prompt/RobustPrompt_T.py:154 → add_muti_pt()

该函数是整个 RobustPrompt-T 的核心防御机制。它在节点特征空间中根据三种标准识别易受攻击的节点，并注入对应的可学习 prompt 向量。

3.2.1 预备：构建 Prompt 记录矩阵

# === 初始化 multi-prompt 记录张量 === g_mutiftpt_record = zeros [2708, 4 × 1433] = zeros [2708, 5732] # 4 种 prompt 各占 1433 维连续区间： # columns [0, 1433) → sim_pt 槽位 # columns [1433, 2866) → degree_pt 槽位 # columns [2866, 4299) → out_detect_pt 槽位 # columns [4299, 5732) → other_pt 槽位

3.2.2 Filter ① — sim_pt（邻居相似度 Filter）

# === Step 1: L2 归一化特征 === x_norm [2708, 1433] = x / ||x||₂ # === Step 2: 逐边 cosine 相似度 === e [|E|, 1] = Σ_d (x_norm[u,d] · x_norm[v,d]) for each edge (u,v) # 每对邻居节点的原始特征相似度 # === Step 3: 逐节点平均邻居相似度 === c [2708, 1] = scatter_add(e, col_index) # 聚合每条边到目标节点 deg [2708, 1] = degree(col) # 各节点度数 csim [2708] = c / deg # 平均邻居 cosine 相似度 # 值域 [-1, 1]，低值 → 邻居特征差异大 → 可疑 # === Step 4: 阈值分选（如 sim_threshold=0.4）=== node_use_sim_pt = { i | csim[i] ≤ 0.4 } # 选出的节点数通常为几十到几百，取决于阈值和图结构 # === Step 5: p_plus 动态 token 组合（可选）=== # p_plus=True 时，对每个选中节点学习加权组合： x_selected [|S_sim|, 1433] ↓ sim_pt_a: Linear(1433, 20) # 为每个节点生成 20-dim 分数 score [|S_sim|, 20] ↓ softmax(dim=1) # 归一化为组合权重 sim_weight [|S_sim|, 20] ↓ sim_weight × sim_pt_list[20,1433] # 加权组合 20 个 token prompt_sim_pt [|S_sim|, 1433] # 每节点定制化的 prompt 向量 # p_plus=False 时，所有选中节点共享同一个 prompt 向量： prompt_sim_pt [1, 1433] # 广播到所有选中节点 # === Step 6: 写入记录矩阵 === g_mutiftpt_record[node_use_sim_pt, 0:1433] = prompt_sim_pt

3.2.3 Filter ② — degree_pt（低度节点 Filter）

# === Step 1: 计算节点度数 === deg [2708] = degree(col, num_nodes=2708) # 每节点入度 # === Step 2: 阈值分选（如 degree_threshold=2）=== node_use_degree_pt = { i | deg[i] ≤ 2 } # 低度节点：信息少、易受攻击影响 # p_plus 同理：degree_pt_a(Linear 1433→20) → softmax → × degree_pt_list[20,1433] prompt_degree_pt → 写入 record[:, 1433:2866]

3.2.4 Filter ③ — out_detect_pt（OOD 边检测 Filter）

# === Step 1: 逐边 cosine 相似度 === x_norm [2708, 1433] = x / (||x||₂ + 1e-12) e [|E|] = Σ_d (x_norm[u,d] · x_norm[v,d]) for each edge (u,v) # === Step 2: 标记 OOD 边 === ood_edge_mask [|E|] = e ≤ ood_threshold # 如 0.5 # ====== OOD 边：两端节点原始特征差异大，很可能是攻击注入的边 ====== ood_edges [2, |E_ood|] = edge_index[:, ood_edge_mask] # === Step 3: 收集 OOD 边端点 === node_use_ood_pt = unique( ood_edges[0] ∪ ood_edges[1] ) # 这些节点参与了"可疑边"，需要特别保护 # p_plus 同理 → prompt_out_detect_pt 写入 record[:, 2866:4299]

3.2.5 Filter ④ — other_pt（增强其余节点）

# === 取所有未被子类型 prompt 覆盖的节点 === all_pt_nodes = unique( node_use_sim_pt ∪ node_use_degree_pt ∪ node_use_ood_pt ) node_use_other_pt = {0..2707} \ all_pt_nodes # mode='all': 取全部其余节点 # mode='random-0.2': 随机取 20% # p_plus 同理 → prompt_other_pt 写入 record[:, 4299:5732]

3.3 核心步骤 B：Self-Attention 融合 → 最终 Prompted Feature

代码: prompt_graph/prompt/RobustPrompt_T.py:283 → 融合部分
# === 重塑：展平 → 三维（节点 × prompt类型 × 特征）=== g_mutiftpt_record [2708, 5732] ↓ .reshape(2708, 4, 1433) g_mutiftpt_record [2708, 4, 1433] # 4 = {sim, degree, ood, other} # ============ 方案 A: Self-Attention 融合（use_attention=True）============ # 1. 拼接 readout_token（可学习汇聚标记） readout_token [1, 1, 1433] # 可学习参数 ↓ .expand(2708, 1, 1433) concat_input [2708, 5, 1433] # [readout, sim_pt, degree_pt, ood_pt, other_pt] # 2. 构建 key_padding_mask（标记哪些 prompt 槽位为空） key_padding_mask [2708, 5] # True = 该槽位全为零（无 prompt） # 3. 最终 Prompted 特征

# === 残差连接：原始特征 + 融合 prompt === g_mutiftpt_final_x = g.x + g_mutiftpt_final_output = [2708, 1433] + [2708, 1433] = [2708, 1433] # 注意：维度不变！Prompt 并非拼接，而是加性注入（残差形式） # 这保证了 Backbone GNN 的 input_dim 仍然是 1433，无需适配

3.4 核心步骤 C：τ-Tune 训练流程（两阶段 GNN Forward）

代码: prompt_graph/prompt/RobustPrompt_T.py:327 → Tune()
关键设计：训练时使用两阶段 GNN Forward（先全图 embedding → τ-tune 剪枝 → 再 forward）， 推理时只做一次 forward 不剪枝。这与 GPromptShield 论文 Equation 15 对齐。
# ============== 第一阶段：Prompted GNN Forward（全边）============== # 输入：已注入 prompt 的特征 + 原始边集 node_emb_intermediate [2708, 128] = GNN( g_mutiftpt_final_x [2708,1433], edge_index [2, |E|] ) # → GCNConv₁(1433→128) + ReLU + Dropout # h₁ ∈ [2708, 128] # → GCNConv₂(128→128) # node_emb_intermediate ∈ [2708, 128] # ============== τ-Tune 边剪枝 ============== # 基于中间 embedding 逐边计算 cosine 相似度 edge_sim_intermediate [|E|] = cos( node_emb_intermediate[u], node_emb_intermediate[v] ) for each (u,v)∈E # 阈值过滤：保留相似度 ≥ pt_threshold 的边 tune_keep_mask [|E|] = edge_sim_intermediate ≥ 0.5 # 默认 τ_tune=0.5 tuned_edge_index [2, |E'|] = edge_index[:, tune_keep_mask] # |E'| ≤ |E|，典型保留 60%-95% 边 # ============== 第二阶段：剪枝后 GNN Forward ============== tuned_g = Data(x=g_mutiftpt_final_x [2708,1433], edge_index=tuned_edge_index [2,|E'|]) node_emb [2708, 128] = GNN( tuned_g.x, tuned_g.edge_index ) # 第二次 forward
τ_tune 的效果：图结构扰动（Metattack）注入的边往往连接特征不相似的节点。 经过 prompt 增强后，这些"坏边"两端节点 embedding 的 cosine 相似度更低， 更容易在 τ_tune 阶段被剪除。两次 GNN forward 的代价是训练时间约 1.8×。

七、关键设计要点

7.1 为什么 Prompt 是"加"而不是"拼"？

g_mutiftpt_final_x = g.x + g_mutiftpt_final_output (RobustPrompt_T.py:316)。 残差形式保证特征维度始终为 [N, 1433]，Backbone GNN 的 input_dim 不需要改变。 如果拼接（如 [N, 1433+1433]），则需要重新训练或适配 GNN 的第一层——这与"冻结 Backbone"的范式冲突。

7.2 三种 Filter 的互补性

Filter识别目标攻击者如何触发选中的节点类型
sim_pt 邻居特征相似度低的节点 Metattack 连接特征不相似的节点对 邻居特征异质的节点
degree_pt 低度节点 低度节点信息少，易被少量扰动边淹没 度 ≤ 2 的节点
out_detect_pt OOD 边端点 攻击边连接原本特征空间相距远的节点 参与至少一条"可疑边"的节点
other_pt 未被以上三种覆盖的节点 — "正常"节点（增强提示）

7.3 τ-Tune 为什么有效？

τ-Tune 的核心思想是 Prompt 先让易受攻击的节点"矫正"其特征表示，再基于矫正后的表示剪除仍不相似的边。 攻击边两端节点的原始特征可能恰好相似（逃过 out_detect_pt），但经过 prompt 增强后， 正常节点和受攻击节点的 embedding 差异被放大，这些"漏网"攻击边在中间 embedding 空间的 cosine 相似度降低， 从而被 τ_tune 剪除。

7.4 p_plus 模式 vs 普通模式

模式Prompt 参数每个节点的 prompt表达能力过拟合风险
GPF (p_plus=False) 1 × 1433 per type 所有同类型节点共享相同 prompt 低 低
GPF-plus (p_plus=True) 20 × 1433 bank + Linear(1433,20) 每个节点学习 20 个 token 的加权组合 高 高（few-shot 下尤其明显）
