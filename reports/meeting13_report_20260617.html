7. 关键发现汇总（贯穿全部四轮实验）

发现 1：τ_tune 不是 NaN 根因

Phase 1 显示 τ_tune 对 clean 图有毒（CE-only ✓ → +τ_tune ✗），但 P1 禁用 τ_tune 后仅从 1/5 改善到 2/5——远不足以实现 5/5 稳定。τ_tune 被排除了"首要嫌疑"地位。

更意外的证据：KL + τ_tune 禁用 (P1b) 全 NaN，而 KL + τ_tune 启用 (Phase 1 Step 4) 有 1/5。说明 τ_tune 和 KL 存在正向协同，τ_tune 并非单纯的破坏者。

发现 2：MSE 正则全面有毒

Phase 1 Step 3 唯一 clean+attacked 均全 NaN。MSE 强制 prompt → 0，在 inductive subgraph 下导致退化表示 + τ_tune 过度剪枝 → NaN。

此后的 P1/P2/P3 全部抛弃 MSE，仅保留 KL 正则。

发现 3：KL 小值有效、大值有毒

kl=0.001 是 Phase 1 唯一跨 clean+attacked 成功的正则。但 P2 显示 kl=0.05 全 NaN、kl=0.1 仅 1/5。

KL 的稳定化作用存在狭窄的"安全窗口"——太小无效、太大崩溃。kl=0.1 峰值 0.633 是全部实验最高记录，但稳定性毫无改善。

发现 4：🎉 prompt_lr 是稳定性关键瓶颈

P3 lr=0.01 首次实现 4/5 clean + 3/5 attacked 稳定。lr=0.001 下 20 次实验无一超过 2/5。

机制推测：低 lr 使 prompt 参数更新缓慢，长时间停留在数值不稳定区域；高 lr 快速逃离危险区，但代价是峰值精度下降（0.615→0.452 clean, 0.477→0.328 attacked）。

lr=0.005 仅 1/5，说明稳定化阈值在 lr∈[0.005, 0.01] 之间。

11. 不稳定性根因分析（经 P1/P2/P3 修正）

1. ~~τ_tune~~ → prompt_lr 过低是主因

Phase 1 怀疑 τ_tune 是 NaN 根因，但 P1 禁用 τ_tune 后仅从 1/5 改善到 2/5。P3 lr=0.01 突破性地达到 4/5 稳定（τ_tune 仍启用），证明真正瓶颈是 prompt_lr。

机制假设：低 lr (0.001) 下 prompt 参数更新极慢，长时间停留在数值不稳定区域（embedding 方差过大 → τ_tune 极端剪枝 → 子图断开 → NaN）。高 lr (0.01) 快速逃离危险区。

2. KL + τ_tune 正向协同

P1b (KL 开启, τ_tune 禁用) 全 NaN，而 KL + τ_tune 启用时有 1/5。

假说：τ_tune 剪枝减少了诱导子图中 defense-token 节点的信息交互，间接降低了 embedding 方差；KL 正则约束 prompt 范数 → 两者协同稳定 cosine 分布。去掉任一方都会打破平衡。

3. 幸存 seed 的随机性 — lr 解释

lr=0.001 下成功 seed 随机且不重叠（s1/s2/s3 各一次）。lr=0.01 下 seed 成功模式变为连续（s1-s5 中 4 个成功）。

低 lr 下，GNN 权重初始化的微小差异决定是否落入"安全区"（1/5 概率）。高 lr 使优化轨迹更鲁棒，不再依赖幸运初始化。

4. 稳定性-峰值 trade-off

lr 0.001→0.01：稳定性 1/5→4/5，但 Clean 峰值 0.615→0.452。

高 lr 降低了 prompt 对特定 defense token 的"记忆"精度——更多 seed 收敛到安全但次优的解。下一步需要在 lr=0.01 的稳定基础上，通过更精细的 defense 阈值和 pt_threshold 调参追回峰值。

这个结果限定了 lr=0.01 有效域：低中污染（ptb≤0.1）。高污染需要更强的防护（如调整 pt_threshold 或 defense 阈值）。

14. 实验 B：lr 继续上探 — 寻找最优 lr

固定：kl=0.001, pt_threshold=0.25, sim=0.2, deg=1, ood=0.4, no MSE。扫描 lr ∈ {0.015, 0.02}，仅 clean/att 0.05

P3 显示 lr 从 0.005→0.01 稳定性飞跃——继续提高会怎样？是否存在 5/5 稳定的 lr？

实验 B 结果（与 P3 lr=0.01 对比）

lr=0.01 是当前探索范围内的 sweet spot。

• lr=0.015：Clean 从 4→3 退化，Att 保持 3/5。lr 太高开始不稳定
• lr=0.02：Clean 回到 4/5 但 Att 降到 2/5——lr 过高时 attacked 图先崩
• 5/5 稳定可能不在纯 lr 提升路径上——需结合其他参数（pt_threshold, KL）联合调节
• 推测：lr 增大的稳定化效果存在上限 (≈0.01-0.012)，超过后优化步长过大引入新的不稳定

15. 实验 C：pt_threshold 调优 — 追回峰值性能

固定：lr=0.01, kl=0.001, sim=0.2, deg=1, ood=0.4, no MSE。扫描 pt_threshold ∈ {0.1, 0.15}，仅 clean/att 0.05

P3 lr=0.01 稳定了但均值偏低（clean 0.345 vs 峰值 0.615）。降低 pt_threshold 可减轻 τ_tune 剪枝强度，理论上提升精度。但会不会让 attacked 图上的可疑边逃脱剪枝？

实验 C 结果（与 P3 pt=0.25 对比）

pt_thresholdptb 0.0 有效ptb 0.0 Best Accptb 0.05 有效ptb 0.05 Best Acc判定
0.25 (P3) 4/50.4523/50.328✅ 最平衡

Clean-Attacked Trade-off 确认：降低 pt_threshold 提升 Clean 但恶化 Attacked。

• pt=0.1：Clean 精度 0.476（比 pt=0.25 提升 5.3%），但 Attacked 从 0.328 断崖跌至 0.202（-38.4%）
• pt=0.15：过渡值，两头不靠——Clean 仅 0.333（比 0.25 差），Att 0.279（比 0.25 差）
• 剪枝强度是 clean-attacked 性能杠杆：剪太少 → attacked 边未清除 → 污染传播；剪太多 → clean 信息丢失
• pt=0.1 下 Att 有效 seed 反增到 4/5——更弱的剪枝让 attacked 训练更稳定，但精度受损（0.202）

这揭示了一个根本困境：单阈值 τ_tune 无法同时适配 clean 和 attacked 图。需要 perturbation-adaptive 策略——根据图受攻击程度动态调整 pt_threshold。
实验 C 关键结论：pt_threshold 是精度-鲁棒性 trade-off 的直接控制杆。
降低 pt（少剪枝）→ clean 精度↑ but attacked 精度↓
提高 pt（多剪枝）→ attacked 精度↑ but clean 精度↓
当前最佳平衡点：pt=0.25（clean 0.452 + att 0.328），但牺牲了 clean 峰值（vs pt=0.1 的 0.476）。
未来方向：perturbation-adaptive pt_threshold，clean 图用低 pt，attacked 图用高 pt。
