Definitions

Task: binary classification of edges — Positive = Anomaly (attack edge, added/deleted by Metattack) vs Negative = Normal (clean original edge).

TP = attack edges correctly flaggedFP = clean edges incorrectly flagged
TN = clean edges correctly left aloneFN = attack edges missed

TPR (Recall) = TP / (TP + FN) — attack edge detection rate.
TNR = TN / (TN + FP) — clean edge preservation rate.
FPR = FP / (FP + TN) = 1 − TNR — false alarm rate. Should be low.
FNR = FN / (FN + TP) = 1 − TPR — miss rate. Should be low.
F1 = 2 × Prec × Recall / (Prec + Recall), where Prec = TP / (TP + FP).
Binary Classification AUC = (TPR + TNR) / 2 — balanced accuracy of the single operating point. Ranges [0, 1], 0.5 = random.

Tip TNR is estimated: (Nclean − FPtip) / Nclean where Nclean comes from the paired Edge Detection line. Inactive tips are grayed out.
