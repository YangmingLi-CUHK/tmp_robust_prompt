两个新增 Filter 的真实前向过程

逐行对应当前 RobustPrompt-T-NSP 主链路，解释 NSP 与 FocusedCleaner-LP 从原始图输入、异常边/节点判定，到 defense prompt 和分类输出的完整维度变化。

先纠正一个关键名词：主算法新增的是两个 defense tip / 异常节点路由分支。NSP 是无可学习参数的结构编码 AkX；只有 FocusedCleaner-LP 含真正的两层 MLP encoder。它们本身都不直接删除主图边，而是决定哪些节点接收对应 prompt。

新增分支一：NSP 的完整前向

入口：nsp_suspicious_nodes(x, edge_index, num_nodes, threshold, order)。默认 order=2。

无参数结构编码

从图到异常边

  1. 输入原始属性与 PyG 边表X [N,F], edge_index [2,E]使用原始 BoW 特征，不使用预训练 GNN embedding，也不使用已加 prompt 的特征。
  2. 构造对称稠密邻接矩阵A [N,N]A[src,dst]=A[dst,src]=1；重复边被压成 1。
  3. k 阶传播并在幂之后清对角
    Aₖ = Ak; diag(Aₖ)=0;   Hnbr = AₖX
    Aₖ [N,N] · X [N,F] → Hnbr [N,F]是长度 k walk count 加权求和；没有度归一化、线性层、ReLU 或 GCN 参数。
  4. 逐条观测边计算端点 cosine
    sₑ = cos(Hnbr,u, Hnbr,v),   aₑ = 1 − sₑ
    [E,F] × [E,F] → sim [E], anomaly_score [E]
  5. 阈值化并把异常边映射为节点
    edge_anomalyₑ = (sₑ ≤ θNSP);   VNSP = unique(src ∪ dst)
    mask [E] → flagged [2,Ea] → nodes [Knsp]

从异常节点到 NSP prompt

默认 p_plus=True，检测器输出的节点再经过与其他 tips 相同的 token-bank prompt 生成器：

X[VNSP] → Linear(F,20) → softmax → α [KNSP,20]
α · TokenBankNSP [20,F] → PNSP [KNSP,F]
张量符号维度Cora
异常节点属性[KNSP, F][KNSP, 1433]
selector logits / weights[KNSP, 20]相同
NSP token bank[20, F][20, 1433]
个性化 NSP prompt[KNSP, F][KNSP, 1433]
NSP 如何定义“异常”
  • 相似度越低越异常；用于 AUC 的连续分数是 1 - cosine。
  • 离散异常边 mask 用 cosine ≤ θ。
  • 任意一条异常边都会把两个端点都放进 V_NSP，属于 OR / 并集规则。
  • NSP 每次 add_muti_pt 都重新计算，但其检测阶段没有可学习参数。
自环细节：当前数据运行时包含自环。dense_adj 没有先移除它们；代码是在算完 Ak 后才清零其对角。令无自环邻接为 B，则默认 order=2 实际使用 A=I+B，且 offdiag(A²)=2B+offdiag(B²)：它同时包含加权的一跳与二跳信息，并非纯二跳。

新增分支二：FocusedCleaner-LP 的完整前向

这是唯一真正包含神经 encoder 的新增分支：node-wise 两层 MLP encoder + inner-product link decoder。

可训练 Link Encoder

阶段 A：构造链接预测训练集

  1. 输入与可选 PCA 增广X [N,F] → X̃ [N,D], D=F+p主 tip 固定使用 pca_dim=0，所以 D=F。PCA 路径若启用，是把 [N,p] 拼回原特征，不是降到 p 维。
  2. 正样本：观测边去自环、无向去重edge_index [2,E] → pos_pairs [M+,2]Metattack 新增边也在观测图中，因此会作为正样本 1 参与训练。
  3. 负样本：随机非边neg_pairs [M−,2], M−=ceil(r·M+)排除自环、全部观测边和重复 pair；默认正负比 1:1。
  4. 合并训练 pair 与标签pairs [B,2], y [B], B=M+ + M−

阶段 B：MLP encoder 与 inner-product decoder

U = ReLU(X̃W₁ᵀ + b₁)    [N,D] → [N,H]
Z = UW₂ᵀ + b₂           [N,H] → [N,H]
logit(u,v) = Σⱼ Zu,jZv,j   [B,H] ⊙ [B,H] → [B]
层权重输入 → 输出
linear1[H,D] + [H][N,D] → [N,H]
ReLU无[N,H] → [N,H]
linear2[H,H] + [H][N,H] → Z [N,H]
inner product无Z[pairs] [B,2,H] → logits [B]

主 tip 只传入 threshold，其余使用默认值：H=D=F、50 epochs、Adam lr=0.1、BCEWithLogits。Cora 中是 1433→1433→1433，共 4,109,844 个局部 detector 参数。

阶段 C：训练、自动选阈值、全边打分

  1. 全 batch 训练 50 epoch
    BCEWithLogits(logits [B], labels [B], pos_weight)
    X.detach()；这个 MLP 有自己的 Adam，不属于主 prompt/GNN optimizer。
  2. 在同一训练 pairs 上选择 ROC-GMean 阈值
    τFC = argmaxt √(TPR(t) · (1−FPR(t)))
    没有单独验证集；正类是观测边，负类是采样非边。
  3. 对全部 PyG edge entries 重新评分
    pₑ = sigmoid(Zᵤ·Zᵥ);   edge_scoreₑ = 1−pₑ
    pred_pairs [E,2] → p_edge [E]
  4. 离散边判定
    edge_keep = (pₑ ≥ τFC);   edge_anomaly = (pₑ < τFC)

阶段 D：从边分数到异常节点

实现并不是“任何低概率边的两个端点全部标异常”。它先对节点所有 incident edge 的异常分数求平均：

qᵥ = meane incident to v(1−pₑ)
node_keepᵥ = (qᵥ ≤ 1−τFC)
node_anomalyᵥ = (qᵥ > 1−τFC) ⇔ mean(pₑ) < τFC

edge_score [E] → scatter sum/count → node_score [N] → anomaly nodes [Kfc]

随后与 NSP 同构：

X[VFC] [KFC,F] → Linear(F,20) → softmax
· TokenBankFC [20,F] → PFC [KFC,F]
阈值语义：主 tip 默认 threshold_mode="gmean"，因此 --pt_focusedcleaner_threshold 0.5 在正常路径通常只是“启用这个 tip”的非负值，并不成为实际 cutoff。实际 cutoff 是上面的自动 τ_FC；传入 0.5 只在 fallback/ROC 退化时使用。

两个分支如何真正影响分类输出

检测结果只改变节点特征上的 prompt；训练期剪边仍由后续 τ_tune 完成。

1 · 写入 Prompt Record

每个 tip 占一个 F 维槽位

record: [N, T·F] → [N,T,F]

T 是当前激活的 prompt 类型数；开全 5 个 detector 时还含 other_pt，所以 T=6。

2 · 融合

默认对激活 prompts 求均值

P = mean(nonzero tip prompts)
P [N,F]

若开启 attention，则加 readout token，输入 [N,T+1,F]，MHA 后取第 0 个 token。

3 · 加到原属性

维度不变

X′ = X + P
[N,F] + [N,F] → [N,F]

随后才进入冻结的预训练 GNN 与分类头。

训练阶段输入操作输出

GNN₁[N,F], [2,E]冻结 backbone 第一次 forwardH₁ [N,Hg]

实现审计：读结果时必须知道的 8 点

这些不是概念推断，而是当前代码实际行为与注释/参数表面的差异。

名词

只有 FC 有可学习 encoder

主链路没有实例化参考文件里的 NSPGCN.forward；NSP 仅复用 AᵏX 邻域表示与 cosine 检测。

FC cutoff

pt_focusedcleaner_threshold 通常不是阈值

默认 GMean 自动选 cutoff；该参数在主 tip 中主要通过“负值移除 / 非负值启用”控制开关。

FC node rule

不是异常边端点 OR

FC 对每个节点 incident edge 分数求平均后才判异常；高 degree 节点的一条坏边可能被其他好边稀释。

缓存

FC 检测器只训练一次并被丢弃

首次 add_muti_pt 局部训练 MLP，之后只缓存 detached masks/scores；MLP 参数不进主 optimizer 或 state_dict。

CLI

filter_lp_* 不控制主 FC tip

主 tip 直接 new filter 且只传 threshold，因此 hidden/epoch/lr/PCA 等 CLI 参数只影响单独的 filter_module 路径。

自环

两条分支都受运行时自环影响

NSP 在 A 中保留自环后再算 Aᵏ；FC 训练 positives 排除自环，但全边评分与节点均值包含自环，且自环 logit 为 ‖zᵢ‖²。

Mask polarity

NSP 两套 API 的 mask 含义相反

nsp_suspicious_nodes 的 True=异常；统一 NSPFilter.forward 的 edge_mask True=保留。主 tip 使用前者。

Factory

factory 注册 NSP，但 CLI choices 漏了它

filter_factory.py 支持 nsp，然而当前 --filter_mode 的 argparse choices 没有 nsp；这不影响直接的 nsp_pt。
